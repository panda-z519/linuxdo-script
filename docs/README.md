# 文档索引

本目录保存项目的详细使用说明。根目录的 [README](../README.md) 负责项目入口、脚本状态和快速开始。

## 相关目录

- [`userscripts/`](../userscripts/README.md)：当前版本的脚本文件，同时是安装地址。
- [`versions/`](../versions/README.md)：已发布版本的历史快照与回滚方式。
- [`tests/`](../tests)：回归测试；[`tools/`](../tools)：仓库维护脚本。
