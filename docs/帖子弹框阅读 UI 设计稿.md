# 帖子弹框阅读 UI 设计稿

## 设计定位

采用“编辑式内容布局 + 克制的磨砂玻璃”。背景列表用于保留浏览上下文，弹框正文用于持续阅读；透明效果集中在遮罩、弹框外壳和标题栏，正文保持高可读性。

不采用全屏面板、黑色浏览器式工具栏、强烈霓虹渐变或正文大面积低透明度。

## 桌面布局

| 项目         | 规格                                |
| ------------ | ----------------------------------- |
| 弹框宽度     | `min(1480px, calc(100vw - 32px))`   |
| 弹框高度     | `min(92vh, 980px)`                  |
| 最小屏幕边距 | `16px`                              |
| 圆角         | `20px`                              |
| 标题栏高度   | `58px`                              |
| 正文宽度     | 占满弹框剩余空间，时间线固定 `96px` |
| 按钮触控区域 | `42×42px`，移动端 `44×44px`         |

弹框水平、垂直居中。原列表从弹框四周可见，仅覆盖低透明度遮罩，不使用模糊。

## 透明层级

| 层级     | 参数                                         |
| -------- | -------------------------------------------- |
| 背景遮罩 | 紫黑色 `10%`，不使用模糊，保证背景列表可辨认 |
| 弹框外壳 | 白色约 `94%`，不使用模糊                     |
| 标题栏   | 白色约 `76%`                                 |
| 正文区域 | 白色约 `98%`                                 |
| 边框     | 半透明白色 `78%`，宽度 `1px`                 |
| 阴影     | `0 24px 70px rgba(42, 35, 78, 0.18)`         |

透明度不直接作用于整个弹框元素，避免文字和图像一起变淡。

## 颜色与字体

- 主强调色：`#6557D8`。
- 强调浅色：`#F0EDFF`。
- 主文字：`#272433`。
- 次级文字：`#716D7D`。
- 页面背景：`#F7F7FB`。
- 字体：系统无衬线字体，优先使用 `Inter`、`-apple-system` 和 `Segoe UI`。
- 正文字号：桌面 `16px / 1.75`，移动端 `15px / 1.7`。

生产实现优先读取 linux.do 已有主题变量，再以以上颜色作为回退值。

## 标题栏

- 标题栏属于弹框内部，不单独悬浮在页面顶部。
- 左侧使用 8px 紫色状态点，不添加“帖子预览”等重复标签。
- 中间显示帖子标题，单行省略。
- 右侧只有展开和关闭两个操作。
- 图标使用统一的 Phosphor 风格 1.8px 线性 SVG：`ArrowsOut` 与 `X`。
- Hover 使用浅紫背景，不改变按钮尺寸和位置。

## 内容与原生功能

- 内容区展示 linux.do 原生主题、帖子和回复。
- 隐藏站点侧边栏。
- 保留点赞、回复、回应、用户卡、图片预览、楼层时间线、通知菜单和原生加载更多。
- 回复编辑器、用户卡和站内对话框显示在弹框之上。
- 内容区域独立滚动，背景列表不滚动。

## 交互

- 普通点击主题：打开居中弹框。
- 展开：移除弹框样式，留在当前原生帖子页。
- 关闭、Esc 或点击弹框外任意遮罩区域：返回来源列表并恢复滚动位置。
- 原生回复编辑器或对话框开启时，Esc 和遮罩点击优先交给原生组件，避免误关闭。
- Command/Ctrl 点击和中键点击保留浏览器行为。

## 动效

- 打开：淡入并从 `scale(0.98)` 过渡到 `scale(1)`，`200ms ease-out`。
- 关闭：淡出并缩小到 `scale(0.985)`，`150ms ease-in`。
- 仅使用 `opacity` 和 `transform`。
- `prefers-reduced-motion: reduce` 时禁用缩放动画。

## 移动端

- 弹框尺寸为 `calc(100vw - 16px)` × `calc(100dvh - 16px)`。
- 四周保留 `8px` 透明边距，圆角 `16px`。
- 标题栏高度 `54px`。
- 操作按钮不小于 `44×44px`。
- 时间线可隐藏，但原生帖子操作继续保留。
- 禁止横向滚动。

## 验收标准

- 桌面端四周可看到原列表，弹框确实水平和垂直居中。
- 不出现黑色通栏或接近全屏的桌面布局。
- 背景可辨认，正文对比度仍满足 WCAG AA（无障碍标准）要求。
- 标题栏处于弹框内部。
- 展开和关闭图标风格、尺寸及笔画一致。
- 浅色、深色、375px、768px、1440px 和减少动态效果模式均可用。
- 原生帖子功能不因视觉层改造而失效。
